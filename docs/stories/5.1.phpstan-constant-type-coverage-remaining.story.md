## Pattern di tipizzazione applicati (part 1)

- `@var string` — per costanti stringa
- `@var int` — per costanti intere
- `@var float` — per costanti float (es. `VAT_PERCENT = 22.0`)
- `@var bool` — per costanti booleane
- `@var null` — per costanti null
- `@var list<string>` — per array list (es. `ACCEPTED_EXTENSIONS = ['ai', 'pdf']`)
- `@var array<string, string>` — per array shape con chiavi generiche
- `@var array{plaque: 'sheet', bar: 'tube', ...}` — per array shape literals (PHPStan non accetta `list<string>` su array con chiavi stringa)
- `@var array<int, array{...}>` — per liste typed con shape (es. `WORKFLOW_STATUSES`)
- `@var list<array{role: string, keyword: string}>` — per regole typed
