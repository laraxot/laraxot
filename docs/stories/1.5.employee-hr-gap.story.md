## Religion

**HR e Employee restano entrambi** (replica SRC + singolare) — **vietato** merge/delete HR “perché c’è Employee”.  
Playbook enable/coesistenza: [debt-replica-auth-hr-enable.md](../../laravel/docs/debt-replica-auth-hr-enable.md).

## Story

As an **HR admin**,
I want **assenze approvabili e CRUD anagrafica dipendente allineati alla BL SRC**,
so that **i widget leave smettono di essere mock e la parity field-service HR è operativa senza cancellare il modulo HR**.

## Acceptance Criteria

1. Model + migration `AbsenceRequest` (type/status/starts/ends/decided_*) dove manca in Employee **oppure** bridge documentato verso HR se già lì.
2. Actions QueueableAction: create / approve / reject.
3. `EmployeeResource` XotBase (anagrafica) oltre a WorkHourResource.
4. Widget leave/pending collegati a DB (no hardcoded).
5. P1: MedicalVisit, Training, Document tipizzati — o esplicitamente deferred con link debt.
6. PHPStan L10 + Pest sul flusso absence.
7. Nessun delete del modulo `HR`.

## Owned File/Module Scope

- Preferire `laravel/Modules/Employee/**` per gap anagrafica/leave usati dai widget Laraxot
- Touch `laravel/Modules/HR/**` solo se serve coesistenza/replica (non per “assorbire”)
- Docs: mapping in comparison + debt D5
