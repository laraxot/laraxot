# Story 2.14 — Quality gate prompt 03: pre-step `composer dump-autoload`

## Contesto

Story 2.11 ha mostrato che `phpstan analyse` può fallire in bootstrap con errore
`Class "Modules\X\Filament\Resources\X" not found` se il class loader è stale
dopo un merge cross-modulo. La soluzione è `composer dump-autoload --no-interaction`.

## Modifica al prompt 03

Aggiungere come **Step 0** del quality gate:

```bash
# 0. Rigenera class loader (risolve errori bootstrap "Class not found" dopo merge)
cd laravel
composer dump-autoload --no-interaction
```
