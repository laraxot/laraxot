## Story

As a **platform engineer**,
I want **tutti i moduli di gestionale_commesse copiati in `laravel/Modules/` e portati alla struttura canonica Laraxot**,
so that **possiamo evolvere il dominio commesse senza riscrivere da zero e senza violare XotBase/nwidart**.

## Acceptance Criteria

1. I 23 moduli SRC esistono sotto `laravel/Modules/<Name>/` (nomi SRC, nessun overwrite di User/Employee/…).
2. Esiste playbook [copy-then-normalize.md](../gestionale-commesse-comparison/copy-then-normalize.md) + canon [module-structure-laraxot-canon.md](../wiki/concepts/module-structure-laraxot-canon.md).
3. `modules_statuses.json` elenca i nuovi moduli (staging `false` per Auth/HR/Documents/AiAssistant/Email/WhatsApp/Platform finché non mergeati).
4. Almeno **un** modulo piccolo (es. Vehicles) è **normalized** (tutto sotto `app/`, composer PSR-4 `app/`, docs dual, root hygiene).
5. Docs nei moduli/temi/wiki aggiornati (second brain).
6. Nessun `git restore`; forward-only.
