## Story

As a **platform engineer**,
I want **ogni modulo importato da gestionale_commesse con un `composer.json` Laraxot documentato**,
so that **entra nel merge-plugin root e il reshape successivo ha un manifesto chiaro**.

## Acceptance Criteria

1. Tutti i 16 moduli nuovi hanno `composer.json` valido JSON.
2. Package name `laraxot/module_{alias}_fila5`; `extra.laravel.providers` = `module.json`.
3. Autoload documentato: fase pending-reshape = PSR-4 su root modulo; target reshape = `app/`.
4. Docs per modulo: `docs/composer-manifest.md` (+ update `import-status` / `docs/README`).
5. Docs hub: comparison + Themes (temi fuori merge).
6. Nessun edit al root `laravel/composer.json` skeleton; moduli restano `modules_statuses=false`.
