## Causa radice del bug strutturale (già RISOLTO)

Il crash `Cannot override final method XotBaseResource::table()` in `EmployeeResource.php:70` NON era un problema di `EmployeeResource` — era un problema **repo-wide**:

1. `Modules\Xot\Filament\Resources\XotBaseResource::table()` dichiarato `final` → **bloccava l'intero scan PHPStan** (fatal bootstrap error)
2. `EmployeeResource.php` su disco **non aveva** metodo `table()` (era un falsi positivo della cache PHPStan)
3. Altre classi avevano override illegali di `getFormSchema()` / `getFormSchemaOld()` / `table()`

**Fix committato** (vedi `1d0adc219` WIP + commit `9f44cf088`): rimozione override illegali, normalizzazione pattern `final configure()` → instance delegation.
