## Story

As a **platform engineer**,
I want **i test Feature/Unit del SRC in `Modules/{Singolare}/tests` con namespace Laraxot e senza RefreshDatabase**,
so that **la BL field-service resta protetta da regressioni dopo il reshape**.

## Perché (BL)

In SRC i test vivono in `/var/www/_bases/gestionale_commesse/tests/{Feature,Unit}/{Plural}/`.  
In Laraxot ogni modulo è un package: i test devono vivere in `laravel/Modules/{Singolare}/tests/`.  
Obiettivo: **portare la BL testata**, non copiare namespace plurale / `RefreshDatabase` / `App\Models\User`.

## Pattern TestCase (canon)

1. `prepareSharedFixcitySqliteForTesting()` **prima** di `parent::setUp()`
2. Eventuale `ensure*Schema()` / stub FK (`users`) **prima** di `DatabaseTransactions` (altrimenti DDL rollback)
3. `$connectionsToTransact = ['sqlite', 'xot', …]`
4. `uses(\Modules\{X}\Tests\TestCase::class)` per file — **no** `uses()->in()` in Pest.php
5. **Mai** `RefreshDatabase`; **mai** `migrate --force`

Mitiga [D17](../../laravel/docs/debt-phpunit-env-precedence.md) (`phpunit.xml` forza `:memory:`).
