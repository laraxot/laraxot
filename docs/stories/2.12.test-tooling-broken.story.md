# Story 2.12 — Pest + PHPInsights ambienti rotti

## Contesto

Quality gate (story 2.8) ha rivelato due problemi ambientali che impediscono l'esecuzione di Pest con coverage e di PHPInsights.

### 1. Pest Xdebug coverage

```bash
cd laravel
./vendor/bin/pest --filter=Modules --coverage
# → ERROR: Unable to get coverage using Xdebug. Did you set Xdebug's coverage mode?
```

Xdebug è installato ma `xdebug.mode` non è impostato a `coverage`. Per generare coverage serve:

```ini
; php.ini o /etc/php/8.x/cli/conf.d/xdebug.ini
xdebug.mode=coverage
```

### 2. PHPInsights TypeError

```bash
cd laravel
./vendor/bin/phpinsights analyse Modules --min-quality=80 --min-complexity=80 --min-style=80
# → TypeError in symfony/console/Input/ArgvInput.php:226
```

Il `phpinsights` installato (nunomaduro/phpinsights) non è compatibile con la versione corrente di `symfony/console`. Serve aggiornamento o downgrade.

## Vincoli

1. `composer.json` root: aggiornamenti consentiti (vedi AGENTS.md — "ALWAYS latest version")
2. Mai downgrade a versioni più vecchie per risolvere
3. `phpstan.neon` NON si tocca
4. Mai toccare `.env.testing` (è read-only)

## Approccio

### 1. Xdebug coverage

**Opzioni:**
- (a) Aggiungere `xdebug.mode=coverage` in `.env.testing` o `phpunit.xml`
- (b) Aggiornare `phpunit.xml` con `coverage` driver alternativo (`pcov` se installato)
- (c) Documentare il comando in `bashscripts/docs/` come "abilitare coverage"

Preferenza: (a) come prima opzione, (b) come fallback se (a) non disponibile.

### 2. PHPInsights

**Comando diagnostico:**

```bash
cd laravel
composer show nunomaduro/phpinsights
composer show symfony/console
./vendor/bin/phpinsights --version
```

**Fix probabile:** aggiornare `nunomaduro/phpinsights` a ultima versione compatibile con `symfony/console` corrente.

## Criteri di accettazione

- [ ] `pest --coverage` produce report (almeno HTML in `build/`)
- [ ] `phpinsights analyse <Modulo>` produce report con metriche
- [ ] Nessuna regressione su altri tool
- [ ] Quality gate (story 2.8) passa end-to-end dopo fix
