# Story 2.10 — Filament audit: 63 Resource senza Schemas/Tables

## Contesto

Audit 2026-09-07 con comando:

```bash
for d in Modules/*/app/Filament/Resources/*Resource; do
  [[ -d "$d" ]] || continue
  missing=()
  [[ -d "$d/Schemas" ]] || missing+=("Schemas")
  [[ -d "$d/Tables" ]] || missing+=("Tables")
  (( ${#missing[@]} > 0 )) && echo "$d — ${missing[*]}"
done
```

**Risultato: 63 Resource in 21 moduli hanno Schemas e/o Tables mancanti.**

## Perché questa story

- `Billing\DeliveryNoteResource` (story 2.9) era il caso manifesto. Fix applicato: creati `Schemas/DeliveryNoteForm.php`, `Schemas/DeliveryNoteInfolist.php`, `Tables/DeliveryNotesTable.php`, Resource ripulito (da `GatedXotBaseResource` → `XotBaseResource`).
- 63 Resource restanti hanno la stessa struttura: `getFormSchema()` + `table()` inline nel Resource, nessuna `Schemas/` o `Tables/`.
- Lo stesso fix in 63 file: ~190 file da creare (Form + Infolist + Table × 63), ~63 Resource da ripulire.

## Vincoli

1. `phpstan.neon` NON si tocca
2. Estendere SOLO `XotBase*` direttamente (NON `GatedXotBaseResource`, NON `LangBaseResource` se non strettamente necessario)
3. `$resource` impostato in Form/Infolist/Table
4. ZERO `->label()` (LangServiceProvider auto-registra via `TransKeyTrait` + `GetTransKeyAction`)
5. `declare(strict_types=1);` su ogni file
6. Mai `git push --force`, mai `revert/reset/checkout`
7. Lock per-file prima di editare (`bashscripts/lock/lock.sh`)
8. Pest verde dopo il fix per ogni modulo
9. PHPStan verde dopo il fix per ogni modulo

## Pattern di fix (validato su DeliveryNoteResource)

```php
// Schemas/DeliveryNoteForm.php
final class DeliveryNoteForm extends XotBaseResourceForm
{
    protected static string $resource = DeliveryNoteResource::class;
    public static function getFormSchema(): array { return [...]; }
}

// Schemas/DeliveryNoteInfolist.php
final class DeliveryNoteInfolist extends XotBaseResourceInfolist
{
    protected static string $resource = DeliveryNoteResource::class;
    public static function getInfolistSchema(): array { return [...]; }
}

// Tables/DeliveryNotesTable.php
final class DeliveryNotesTable extends XotBaseResourceTable
{
    protected static string $resource = DeliveryNoteResource::class;
    public function getTableColumns(): array { return [...]; }
    public function getTableFilters(): array { return [...]; }
    public function getTableBulkActions(): array { return [...]; }
}

// DeliveryNoteResource.php — RIPULITO
final class DeliveryNoteResource extends XotBaseResource
{
    // SOLO navigation + label + helper static
    // NIENTE getFormSchema() o table() inline
}
```

## Criteri di accettazione (per modulo)

- [ ] `Schemas/<Name>Form.php` esiste, estende `XotBaseResourceForm`, `$resource` impostato, zero `->label()`
- [ ] `Schemas/<Name>Infolist.php` esiste, estende `XotBaseResourceInfolist`, `$resource` impostato, zero `->label()`
- [ ] `Tables/<Plural>Table.php` esiste, estende `XotBaseResourceTable`, `$resource` impostato
- [ ] Resource estende `XotBaseResource` direttamente (NON `GatedXotBaseResource`)
- [ ] Resource ha SOLO navigation + label + helper static (no `getFormSchema()`, no `table()` inline)
- [ ] PHPStan verde sul modulo
- [ ] Pest verde sul modulo
- [ ] `git status` pulito, push completato
- [ ] Second brain aggiornato

- `phpstan` rotto a livello globale (vedi story 2.11) — fix wave per wave quando bootstrap sarà risolto
