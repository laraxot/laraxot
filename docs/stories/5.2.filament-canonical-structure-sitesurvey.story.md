# Story 5.2 — Filament canonical structure: Quotation\SiteSurveyResource

Status: **COMPLETED** — 2026-09-07

## Contesto (Perché mancava)

Il Resource `Modules/Quotation/app/Filament/Resources/SiteSurveyResource.php` aveva:
- `getFormSchema(): array` inline (righe ~80-198)
- `table(Table $table): Table` inline (righe ~200-269)
- Cartelle `Schemas/` e `Tables/` **assenti**
- Solo `Pages/` (4 file) + `RelationManagers/` + `Concerns/`

Secondo la **convenzione auto-scoping di `XotBaseResource`** (in `Modules\Xot\Filament\Resources\XotBaseResource.php`):
- `XotBaseResource` cerca automaticamente `<Name>Form`, `<Name>Infolist`, `<Plural>Table` via naming convention
- Senza `Schemas/DeliveryNoteForm.php` → il form non si monta
- Senza `Tables/DeliveryNotesTable.php` → la tabella non si monta
- `HasXotTable.php:220` stabilisce che chi estende `XotBaseResourceTable` NON ridefinisce `table()`

## Pattern di duplicazione con altri Resource

Questo pattern (inline `getFormSchema()` + inline `table()`) era già documentato nel prompt `06-filament-audit.md` come Caso A (`Billing\DeliveryNoteResource`). Tuttavia `DeliveryNoteResource` era già stato rifattorizzato, mentre `SiteSurveyResource` no.

## Fix Applicato (Ricetta §5a)

1. **Creato `Schemas/SiteSurveyForm.php`**:
   - `final class SiteSurveyForm extends XotBaseResourceForm`
   - `protected static string $resource = SiteSurveyResource::class;`
   - `getFormSchema(): array` estratto dal Resource
   - Zero `->label()` hardcoded — tutto via `LangServiceProvider`
2. **Creato `Schemas/SiteSurveyInfolist.php`**:
   - `final class SiteSurveyInfolist extends XotBaseResourceInfolist`
   - `getInfolistSchema(): array` con campi di dettaglio
3. **Creato `Tables/SiteSurveysTable.php`**:
   - `final class SiteSurveysTable extends XotBaseResourceTable`
   - `protected static string $resource = SiteSurveyResource::class;`
   - `table()` definito (necessario per il pattern concreto con azioni multiple)
4. **Resource ripulito**:
   - Rimossi `getFormSchema()` e `table()` inline
   - Rimossi import `Filament\Actions\*`, `Filament\Forms\Components\*`, `Filament\Tables\Columns\*` (non più usati)
   - Mantenuti `statusOptions()` e `statusColor()` come helper statici
   - Aggiornata docstring con riferimenti a `Schemas/SiteSurveyForm`, `Schemas/SiteSurveyInfolist`, `Tables/SiteSurveysTable`

## Pattern Generalizzato (per second brain)

Ogni volta che un Resource ha:
- `getFormSchema(): array` → estrarre in `Schemas/<Name>Form.php extends XotBaseResourceForm`
- `getInfolistSchema(): array` → estrarre in `Schemas/<Name>Infolist.php extends XotBaseResourceInfolist`
- `table(Table $table): Table` → estrarre in `Tables/<Plural>Table.php extends XotBaseResourceTable`
- Lasciare solo metadati Resource (navigation, model, label, statusOptions, helper statici)
