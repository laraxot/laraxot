### Inline Form senza Tables (parziali): 45 Resources

Subset delle 58 che hanno Table inline nel Resource stesso (oltre a Form inline).

### Inline Infolist: 5 Resources

Risorse che hanno `getInfolistSchema()` ridefinito nelle Pages invece di usare
`Schemas/<Name>Infolist.php`.

### Perché è urgente

1. **Code quality**: 125/314 Resources (39%) hanno schema inline — impossibile
   mantenere, testare, riutilizzare.
2. **Bootstrap risk**: `GatedXotBaseResource` in Platform rompe l'intero bootstrap
   Filament quando viene rimosso il bridge `GatedXotBaseResource` (issue #10).
3. **Multi-agent parallelo**: 44 moduli, 58 gap completi — nessun singolo agente
   può farcela in tempo ragionevole. Swarm obbligatorio.

### Per ogni Resource: steps canonici

1. Estrai `getFormSchema()` dal Resource → `Schemas/<Name>Form.php`
2. Estrai `table()` dal Resource → `Tables/<Plural>Table.php`
3. Estrai `getInfolistSchema()` dalla Page → `Schemas/<Name>Infolist.php`
4. Slimma il Resource: rimuovi metodi inline, mantieni solo navigation/pages/relations
5. Verifica `phpstan` + `pint`
6. Aggiorna `docs/filament/patterns.md` del modulo
7. Crea story BMAD dedicata per il modulo

### BMAD tools da usare

- `bmad create story` per ogni modulo (story figlia: 4.14.1, 4.14.2...)
- `bmad brainstorm` per risolvere casi complessi (WorkOrder, Customer con NavigationGate)
- `bmad research` per pattern non chiari
- Second brain update dopo ogni modulo completato

## Verify

Per ogni modulo swarmato:

- [ ] Resource ha `Schemas/<Name>Form.php` + `Schemas/<Name>Infolist.php` + `Tables/<Plural>Table.php`
- [ ] Resource.php non ha `getFormSchema()` / `table()` / `getInfolistSchema()` inline
- [ ] PHPStan → 0 errori sul modulo
- [ ] Pint → passed
- [ ] `docs/filament/patterns.md` aggiornato
- [ ] Story BMAD del modulo chiusa

## Note

I moduli `Lang` (LangBaseResource) e `Rating` (BaseRating*) sono **abstract base
classes** — NON risorse utilizzabili, NON devono essere refactorate. Platform
(`GatedXotBaseResource`) è un **anti-pattern** da rimuovere, non da refactorare.
