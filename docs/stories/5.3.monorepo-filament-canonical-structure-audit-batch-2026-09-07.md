# Story 5.3 — Monorepo Filament Canonical Structure Audit (Batch)

Status: **IN PROGRESS** — session 2026-09-07 batch

## Contesto (Perché questo audit)

Il prompt `06-filament-audit.md` stabilisce che ogni `Filament/Resources/*Resource.php` deve avere `Schemas/`, `Tables/`, `Pages/`, `RelationManagers/` e zero `getFormSchema()` / `table()` inline. Dopo aver chiuso `DeliveryNoteResource` (story 4.1) e `SiteSurveyResource` (story 5.2), l audit completo rivela 50+ file con gap.

## Ricognizione (Audit batch — swarm)

Risultati audit completo (comando: `for r in Modules/*/app/Filament/Resources/*.php`):

### OK — Nessun gap
- AiAssistant, Billing (DeliveryNoteResource OK), Blog, Compliance (parziale), HR, Intervention, Job, MetalWork, Platform, Production, PublicProcurement, Quotation (SiteSurveyResource OK), Signage, Timber, Vehicle, WorkOrder, Wts

### Gap critici — Catalog (6 Resource)
- `BomResource`, `CatalogFrequencyResource`, `CatalogMeasureUnitResource`, `CatalogModelResource`, `CatalogPartTypeResource`, `MetelCatalogResource`, `ProductResource`
- Tutti: `form_inline=1`, `table_inline=1`, `schemas=0`, `tables=0`
- Ricetta: §5a su ciascuno

### Gap critici — Customer (8 Resource)
- `ResellerResource`, `CustomerSystemResource`, `CustomerResource`, `AddressResource`, `LocationResource`, `AbsenceRequestResource`, `EmployeeResource`
- Mix: alcuni hanno `schemas=1` ma `form_inline=1` (non delegano)

### Gap — Gdpr (4 Resource)
- `ProfileResource`, `TreatmentResource`, `ConsentResource`, `EventResource`
- `schemas=1` ma `form_inline=1` — il Resource non delega al Schema

### Gap — Compliance (4 Resource)
- `CustomerSystemResource`, `HeatingSystemResource`, `EquipmentResource`, `SubcontractorResource`
- Tutti: `form_inline=1`, `table_inline=1`, `schemas=0`, `tables=0`

## Approccio swarm + subagent

Per batch da 5 file:
1. Subagent prende modulo + 5 Resource
2. Esegue audit (`filament_audit.sh <M>`) + ricetta §5a
3. Quality gate (`php -l`, `phpstan`, `pint`)
4. Commit forward-only con story ID

## Definizione di "Completato"

- [ ] Catalog: 7 Resource con Schemas + Tables estratti
- [ ] Customer: 7 Resource con Schemas + Tables estratti
- [ ] Gdpr: 4 Resource con delegazione al Schema
- [ ] Compliance: 4 Resource con Schemas + Tables estratti
- [ ] Nessuna soppressione, `phpstan.neon` non toccato
- [ ] Second brain aggiornato con il pattern di estrazione
