# Story 7.2 — DISCOVERED: Pattern consolidato 3-trait (Table/Form/Infolist)

Cosa è stato scoperto in sessione 2026-09-07:

1. `HasXotTable` (esiste) — instance methods + final `table()` wrapper
2. `HasXotForm` (esiste, fixato in sessione) — aveva `->columns(2)` hardcoded e `getFormColumns()` phantom
3. `HasXotInfolist` (NON esisteva, creato in sessione) — copiato pattern

Regola canonica:

```php
trait HasXotX {
    abstract public function getXSchema(): array;
    public function getXSchemaColumns(): int { return 1; }  // default
    final public function x(Schema|Table $s): Schema|Table {
        return $s->components($this->getXSchema())->columns($this->getXSchemaColumns());
    }
}

abstract class XotBaseResourceX {
    use HasXotX;
    public static function configure(... $x): ... {
        $instance = app(static::class);
        return $instance->x($x);
    }
}
```

Da applicare a:

- `XotBaseResourceTable` (story 6.0 — refactor non ancora fatto)
- `XotBaseResourceForm` (story 7.1)
- `XotBaseResourceInfolist` (FATTO, vedi `HasXotInfolist.php`)
