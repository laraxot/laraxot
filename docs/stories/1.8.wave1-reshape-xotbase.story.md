## Acceptance Criteria

1. Ogni modulo Wave 1 ha `app/Models/BaseModel.php extends XotBaseModel`; tutti i model owner lo estendono (no `extends Model` diretto).
2. Ogni `*Resource` Filament estende `XotBaseResource` (o LangBase se pattern modulo); Pages via XotBase page types dove applicabile; **niente** `Filament\Resources\Resource` diretto.
3. Actions in `app/Actions` usano QueueableAction (o trait progetto) — niente Service class nuova.
4. Artifact parity: N model owner ⇒ N factory + N seeder; migrations consolidate (1 `create_*` per model, bump timestamp).
5. `lang/it`+`en` minimi; no `->label('…')` hardcoded nei form nuovi/toccati.
6. Pest smoke + PHPStan L10 su `Modules/{Customers,WorkOrders,Interventions}`.
7. Solo dopo 1–6: `modules_statuses.json` → `true` per i tre.
8. Docs: aggiornare `import-status.md` + `composer-manifest.md` + gap file per modulo; Themes note FO operator.

### Connessione DB per modulo (risolto 2026-07-23)

`XotBaseModel` default `connection = 'xot'`. Ogni modulo Wave 1 ha `BaseModel` con connection = `Module::getSnakeName()` (`customers`, `work_orders`, `interventions`). `TenantServiceProvider::mergeModuleConnections` clona la connection default per ogni modulo **abilitato**. Shim: `laravel/app/Support/AccountFeatures.php` (permissivo) finché non si porta la matrice pannelli SRC in Tenant/User.
