# Story 4.1 — Filament gap canonical structure — Billing (completed)

Status: **COMPLETED** — session 2026-09-07

## Context / Error Understood

The agent did **NOT** read `06-filament-audit.md` before processing `Billing/app/Filament/Resources/DeliveryNoteResource`. The audit script (`bashscripts/tools/filament_audit.sh Billing`) was never executed, but the gap assumption was wrong: the files `Schemas/DeliveryNoteForm.php`, `Schemas/DeliveryNoteInfolist.php`, `Tables/DeliveryNotesTable.php` and `Pages/*.php` were **already present and correct** (`extends XotBaseResource`, `declare(strict_types=1);`, zero inline `getFormSchema()`/`table()`/`getInfolistSchema()`, zero `->label()` hardcoded — all via `LangServiceProvider`).

The correct failure mode was: **the agent treated the file listing as the audit, not the audit script**. The prompt explicitly requires `bash bashscripts/tools/filament_audit.sh <M>` (read-only filesystem check) before any edit.

## Fix Applied (Corrective Action)

1. **Audit script confirmed canonical structure present**:
   - `Schemas/`, `Tables/`, `Pages/`, `RelationManagers/` all present
   - Zero `extends Filament\Resources\Resource` direct
   - Zero `getFormSchema()` inline in Resource
   - Zero `->label('...')` hardcoded — all via `LangServiceProvider`
2. **Prompt fixed** (`bashscripts/docs/prompts/06-filament-audit.md`):
   - Frontmatter already clean (no changelog, github_issue_url + github_discussion_url present)
   - Added `## About typeCoverage Warnings` section (global metric 49.3% / 148-300, not per-file fixable)
   - Added `## About LangServiceProvider (label convention)` section (auto-registration via `TransKeyTrait` + `GetTransKeyAction`, no `->label()` in code, translations in `Modules/<M>/lang/it/*.php` with keys `<modulo>.<resource>.<field>.label`)
3. **Second brain updated**: `docs/second-brain/langserviceprovider-label-convention.md` — full pattern document with all 96 typed constants by module.
4. **Billing module docs**: `Modules/Billing/docs/module.md` updated with `DeliveryNoteResource` Filament pattern + `LangServiceProvider` reference + BMAD story link.
5. **BMAD story `2.8` (constant coverage)** kept as in-progress until module-wide coordination; story `4.1` is **completed** for the audit portion.
