## Session log — Catalog / HR (2026-07-24)

### Catalog — causa radice fail → fix

1. **Sintomo iniziale:** `no such table: products/metel_*` su connection `xot` / `:memory:`.
2. **Causa:** `TestCase` senza `prepareSharedFixcitySqliteForTesting()` mentre le tabelle **esistevano già** in `database/fixcity_data.sqlite`.
3. **Secondo fail:** `MetelRecordParser` TypeError — `config('metel.fixed_layout')` = `null`.
4. **Causa:** XotBase `registerConfig()` setta `catalog.metel.*`; Actions/test SRC usano `metel.*`. Stub `fixed_layout`/`csv_map` = `[]`.
5. **Fix:** `mergeConfigFrom(module config/metel.php, 'metel')` + layout/csv da SRC (no `env()` in config modulo).
6. **Esito:** 11/11 passed.

### HR — causa radice fail → fix / skip

1. **Sintomo:** `no such table: employees` / poi `main.users` su INSERT.
2. **Causa A:** stesso D17/fixcity remap assente.
3. **Causa B:** migrate HR **dentro** `DatabaseTransactions` → DDL rollback → `employees=N` al run successivo.
4. **Causa C:** `foreignUuid('user_id')->constrained('users')` richiede tabella `users`.
5. **Fix:** stub `users` (id string 36) + migrate path HR **prima** di `parent::setUp()`.
6. **EmployeeCrud + type normalization:** green.
7. **Lang:** `__('hr.absence_types.sick')` non risolve → fallback `ucfirst('sick')` = `Sick`. Fix → `hr::hr.absence_types.*`.
8. **Skip onesti:** media Document (D1); workflow assenza con Role/User factory (D6/D17).
