## Story

As a **platform engineer**,
I want **schema applicato (path-scoped) e panel Filament registrati** per i moduli wave,
so that **CRUD/operator non restano «enabled ma inutilizzabili»**.

## Acceptance (evidenza)

- [x] Tabelle core: customers, work_orders, interventions, quotations, signatures, vehicles, ai_*
- [x] Nessun `migrate --force`
- [x] Preferire `php artisan migrate --path=Modules/{X}/database/migrations` (E13) — evitare global migrate (~95 Pending legacy → D3)
- [x] AdminPanelProvider in `module.json` + `composer.json` per WorkOrder, Intervention, Quotation, Signature, Vehicle, AiAssistant (E12)
- [x] `route:list` espone `*/admin` per quei moduli
- [x] Docs: [functional-readiness.md](../gestionale-commesse-comparison/functional-readiness.md) + import-status moduli
- [x] Pest smoke minimo: Customer Actions, CreateWorkOrder, CreateIntervention, VehicleCrud (dettaglio → [2.5](./2.5.migrate-gestionale-tests.story.md))
- [ ] Document media rename (blocked by design — [D1](../../laravel/docs/debt-document-media-conflict.md))
- [ ] Suite Pest wave completa senza fail spuri
