# 5.72.19 Quotation Filament canonical structure

## Understand

The Xot canonical pattern for Filament resources requires three extracted
classes per resource:

- `Schemas/<Name>Form` extending `XotBaseResourceForm`
- `Schemas/<Name>Infolist` extending `XotBaseResourceInfolist`
- `Tables/<PluralName>Table` extending `XotBaseResourceTable`

`XotBaseResource::form()` / `table()` / `infolist()` resolve these classes
automatically (see `Modules/Xot/app/Filament/Resources/XotBaseResource.php:134`
and `:200`). Inline `getFormSchema()` / `table()` / `getInfolistSchema()` on
the Resource are a migration bridge only.

State of the three Quotation resources at the start of this task:

- `QuotationResource` — inline `getFormSchema()` + `table()` on the Resource,
  `Schemas/QuotationForm` and `Tables/QuotationsTable` already exist.
  No infolist.
- `QuotationTemplateResource` — same situation: inline schema/table on the
  Resource, `Schemas/QuotationTemplateForm` and `Tables/QuotationTemplatesTable`
  already exist. No infolist.
- `SiteSurveyResource` — already canonical (Form + Table + Infolist extracted).

Goal: finish migration by removing inline schema/table from the two
remaining resources and adding the missing Infolists.

## Plan

1. `QuotationResource` — drop inline `getFormSchema()` + `table()`; keep only
   metadata, navigation labels, relations, pages, account-feature guards,
   and the shared `marginSummary()` / `marginColour()` helpers (also used by
   the table column and the new infolist).
2. `QuotationTemplateResource` — drop inline `getFormSchema()` + `table()`.
3. `SiteSurveyResource` — drop inline `getFormSchema()` + `table()` (form
   helper functions `statusOptions()` / `statusColor()` stay on the
   resource because they are referenced from the extracted Form/Table).
4. Add `QuotationResource/Schemas/QuotationInfolist` extending
   `XotBaseResourceInfolist`, mirroring the form sections (code/financials/
   notes) and using the resource's `marginSummary()` helper for the margin
   row.
5. Add `QuotationTemplateResource/Schemas/QuotationTemplateInfolist` with
   title + notes sections.
6. No hardcoded `->label()` strings in the new infolists — translation keys
   are resolved by `LangServiceProvider` / `TransTrait` upstream.
