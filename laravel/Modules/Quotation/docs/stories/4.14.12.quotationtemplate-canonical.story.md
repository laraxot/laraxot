# Story 4.14.12 — QuotationTemplate — Filament canonical structure

## Understand

### Problem

`Modules/Quotation/app/Filament/Resources/QuotationTemplateResource.php` (120 righe) carica
inline `getFormSchema()` (Section con TextInput title + Textarea notes) e `table()` (colonne
title + updated_at, recordActions View/Edit, toolbarActions Delete/Restore/ForceDelete).

`QuotationResource` (438 righe) è già in lavorazione parallela da altro agente (story 4.13)
— fuori scope. `QuotationTemplateResource` è la prossima entità inline del modulo.

Modello: `QuotationTemplate` (SoftDeletes) → richiede `RestoreBulkAction` /
`ForceDeleteBulkAction` oltre a `DeleteBulkAction` (patterns.md bug #1).

`QuotationTemplateResource` usa trait `HasAccountFeatureVisibility` + costanti
`ACCOUNT_FEATURE_ADMIN` / `ACCOUNT_FEATURE_OPERATOR` e metodo protetto
`isAvailableInCurrentPanel()` → **tutti da mantenere nel Resource slim** (non è
configurazione, è logica di gating). AGENTS.md regola hard: "se ha HasAccountFeatureVisibility
trait, mantienilo nel Resource".

### Applicabilità

- **Contratto**: `XotBaseResource.php:135-152` auto-scopre `Schemas/<Name>Form.php` via
  `class_basename(static::getModel())` → qui `QuotationTemplate` → `QuotationTemplateForm`.
- **Table**: `XotBaseResource::getTableClass()` risolve
  `Tables/<Plural class_basename Model>Table` → `QuotationTemplatesTable`.
- **Infolist**: nessuna esposta (`getInfolistSchema()` non presente, nessuna page `view`
  strutturata con schema) → nessun file `QuotationTemplateInfolist.php` creato.
- **Pattern canonico**: `Modules\Gdpr\Filament\Resources\ConsentResource\Schemas\ConsentForm.php`
  + `Modules\Billing\...\InvoiceForm.php` come riferimento.

### Root cause

Il Resource è stato scritto prima del prompt `06-filament-audit.md` v3.0.0 e non ha mai
ricevuto l'estrazione Schemas/Tables.

## Plan

1. Crea `QuotationTemplateResource/Schemas/QuotationTemplateForm.php` con
   `getFormSchema()` + `getFormSchemaColumns(): int = 2`, `$resource` protetto statico.
2. Crea `QuotationTemplateResource/Tables/QuotationTemplatesTable.php` con `getTableColumns()`
   + `getTableActions()` (View/Edit iconButton) + `getTableBulkActions()` (Delete+Restore+
   ForceDelete — modello SoftDeletes).
3. Slimma `QuotationTemplateResource.php`: rimuovi `getFormSchema()` + `table()` + import
   inutilizzati (`Filament\Actions\*`, `Filament\Forms\*`, `Filament\Schemas\*`, `Filament\Tables\*`).
4. Mantieni nel Resource slim: trait `HasAccountFeatureVisibility`, costanti
   `ACCOUNT_FEATURE_ADMIN/OPERATOR`, `getNavigationGroup/ModelLabel/PluralModelLabel`,
   `isAvailableInCurrentPanel()`, `getRelations()`, `getPages()`.
5. `php -l` su tutti e 3 i file.
6. `pint --dirty --test` su Quotation.
7. `phpstan` su Quotation (limitato ai file toccati: bloccato da bug pre-esistente
   `BaseProfileResource.php:22` doppio `#[\Override]` in modulo User — fuori scope).

## Implement

### Step 1 — `Schemas/QuotationTemplateForm.php`

```php
final class QuotationTemplateForm extends XotBaseResourceForm
{
    protected static string $resource = QuotationTemplateResource::class;

    public function getFormSchemaColumns(): int { return 2; }

    public function getFormSchema(): array
    {
        return [
            'title' => Section::make()->columnSpanFull()->components([
                TextInput::make('title')->required()->maxLength(255),
                Textarea::make('notes')->columnSpanFull(),
            ])->columns(2),
        ];
    }
}
```

### Step 2 — `Tables/QuotationTemplatesTable.php`

```php
final class QuotationTemplatesTable extends XotBaseResourceTable
{
    protected static string $resource = QuotationTemplateResource::class;

    public function getTableColumns(): array { /* title + updated_at toggleable */ }
    public function getTableActions(): array   { /* View + Edit iconButton */ }
    public function getTableBulkActions(): array
    {
        return ['delete' => Delete, 'restore' => Restore, 'forceDelete' => ForceDelete];
    }
}
```

### Step 3 — Resource slim

Da 120 → 79 righe. Rimosse: `getFormSchema()`, `table()`, 10 import non più usati.

### Step 4 — Mantenuto

Trait `HasAccountFeatureVisibility` + 2 costanti + `isAvailableInCurrentPanel()` →
in viola il Resource slim. Le costanti sono lette via reflection dal trait, spostarle
romperebbe il wiring.
