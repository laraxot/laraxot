# BMAD Story — Remove Duplicate HasXotFactory Trait Usage

## Understand
- **Problem**: 34 model files across modules use `use HasXotFactory;` but they extend a BaseModel (or similar) that already inherits from XotBaseModel which already has HasXotFactory. This causes PHPStan duplicate trait use errors.
- **Rule**: Only models extending `XotBaseModel` directly should use `HasXotFactory`. Models extending module-specific `BaseModel` (which extends XotBaseModel) should NOT use it.
- **Applicable rules**: 
  - XotBaseModel already has `use HasXotFactory`
  - Module BaseModel extends XotBaseModel
  - Child models extend BaseModel → inherit HasXotFactory automatically

## Plan
1. Identify all 34 affected files (done)
2. For each file: remove `use Modules\Xot\Models\Traits\HasXotFactory;` import and `use HasXotFactory;` trait
3. Run phpstan + phpmd + phpinsights + pest per module
4. Git sync per module
