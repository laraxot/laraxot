# Refactor AiAssistant to Delegate to AI Module Handlers

## Objective

Replace direct LLM calls in AiAssistant with delegated calls to AI module's handler abstraction. Eliminate duplication, reduce module size, and make AiAssistant a thin domain orchestrator instead of an LLM infrastructure consumer.

## Context

**Current State:**
- AiAssistant calls OpenAI and Groq APIs directly
- Duplicate LLM logic (retry, parsing, context compression)
- Extractors (`OpenAiQuotationDraftExtractor`, etc.) hardcoded to specific providers
- No abstraction layer for switching providers

**Blocker:** Depends on AI story `01.consolidate-aiassistant-handlers`. AI module must first extract handlers.

**Why This Story Follows:** Once AI module has `QuotationDraftHandler`, `InterventionReportHandler`, etc., AiAssistant refactors to call them.

## Deliverables

### 1. Remove Direct LLM Imports (Phase 1)

Replace hardcoded provider calls with handler delegation:

**OLD:**
```php
use OpenAI\Client;

class OpenAiQuotationDraftExtractor {
    public function extract($document): QuotationDraftData {
        $client = OpenAI::client();
        $response = $client->chat()->create([...]);
        return $this->parse($response);
    }
}
```

**NEW:**
```php
use Modules\AI\Support\AiActionHandlerRegistry;

class OpenAiQuotationDraftExtractor {
    public function __construct(private AiActionHandlerRegistry $handlers) { }
    
    public function extract($document): QuotationDraftData {
        return $this->handlers->get('quotation-draft')->handle([
            'document' => $document,
        ]);
    }
}
```

### 2. Refactor Extractors (Phase 1)

Update all extractors to delegate to AI handlers:

- `OpenAiQuotationDraftExtractor` → delegate to `AI::QuotationDraftHandler`
- `OpenAiInterventionReportExtractor` → delegate to `AI::InterventionReportHandler`
- `OpenAiQuotationModificationExtractor` → delegate to `AI::QuotationModificationHandler`
- `OpenAiWhisperTranscriptionProvider` → delegate to `AI::SpeechTranscriptionHandler`
- `GroqWhisperTranscriptionProvider` → delegate to `AI::SpeechTranscriptionHandler`

### 3. Update Proposals Workflow (Phase 1)

Proposals (`CreateAiActionProposalAction`, `ExecuteAiActionProposalAction`) now call handlers via registry:

```php
class CreateAiActionProposalAction {
    public function execute(
        $context,
        AiActionHandlerRegistry $handlers,
        string $handlerKey
    ): AiActionProposal {
        $result = $handlers->get($handlerKey)->handle($context);
        return AiActionProposal::create([
            'handler_key' => $handlerKey,
            'result' => $result->toJson(),
        ]);
    }
}
```

### 5. Test Refactoring (Phase 2)

Update all tests to mock `AiActionHandlerRegistry` instead of OpenAI/Groq:

**OLD:**
```php
test('quotation draft extraction', function () {
    $this->mock(OpenAI::class)
        ->shouldReceive('client')
        ->andReturn($mockClient);
    
    $result = app(OpenAiQuotationDraftExtractor::class)->extract($pdf);
    expect($result)->toBeInstanceOf(QuotationDraftData::class);
});
```

**NEW:**
```php
test('quotation draft extraction', function () {
    $mockHandler = Mockery::mock(AiActionHandlerContract::class);
    $mockHandler->shouldReceive('handle')
        ->andReturn(new QuotationDraftData(...));
    
    app()->bind(AiActionHandlerRegistry::class, fn() => new MockRegistry($mockHandler));
    
    $result = app(OpenAiQuotationDraftExtractor::class)->extract($pdf);
    expect($result)->toBeInstanceOf(QuotationDraftData::class);
});
```

## Related Issues & Decisions

**Design Decision:** Extractors wrap handlers, don't inherit
- **Rationale:** Extractors are contracts implemented by multiple providers; wrap to maintain interface
- **Alternative:** Delete extractors, use handlers directly
- **Decision:** Keep extractor interface; delegate to handlers internally

**Design Decision:** Handler registry passed via dependency injection
- **Rationale:** Testable; easy to mock in tests
- **Alternative:** Service locator (`app(AiActionHandlerRegistry::class)`)
- **Decision:** Constructor injection preferred

## Risks & Mitigations

| Risk | Mitigation |
|------|-----------|
| Tests break during refactor | Refactor tests first (mock handlers), then code |
| Handler not found at runtime | Register all handlers in AI's service provider; add guard clauses |
| Performance regression | Profile before/after; handlers should be as fast or faster |
| Breaking changes for consumers | API unchanged (extractors still work); internal delegation only |
