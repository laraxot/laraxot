# BMAD Story — Fix PHPStan Cast Errors (AiAssistant)

## Understand
- **Problem**: 22 PHPStan `cast.string`/`cast.int`/`cast.double` errors in AiAssistant module
- **Root Cause**: Casting `mixed` types from `data_get()` and `config()` without type guards
- **Rule**: PHPStan level 8 requires type-safe casts — cannot cast `mixed` directly

## Plan
1. Fix `BuildSpokenSummaryAction.php:41` — cast to string
2. Fix `AiAssistantServiceProvider.php:59` — cast to int
3. Fix `OperatorAssistantAgent.php:1246,1253,1277` — cast to float/string
4. Fix `AiCommunicationsMonitor.php:299,300` — unnecessary coalesce
5. Verify with PHPStan and pest

## Implement

### 1. BuildSpokenSummaryAction.php
```php
// Before
$trimmed = is_string($line) ? trim($line) : trim((string) $line);

// After
$trimmed = is_string($line) ? trim($line) : '';
```

### 2. AiAssistantServiceProvider.php
```php
// Before
: max(1, (int) ($maxProposalsValue ?? 30));

// After
: max(1, is_numeric($maxProposalsValue) ? (int) $maxProposalsValue : 30);
```

### 3. OperatorAssistantAgent.php
```php
// Before
'confidence_score' => (data_get($document, 'confidence_score')) === null ? null : (float) data_get($document, 'confidence_score'),
'score' => (float) data_get($match, 'score'),
if (in_array((string) data_get($document, 'analysis_status', ''), ['needs_review', 'failed'], true)) {

// After
'confidence_score' => ($val = data_get($document, 'confidence_score')) !== null && is_numeric($val) ? (float) $val : null,
'score' => ($val = data_get($match, 'score')) !== null && is_numeric($val) ? (float) $val : 0.0,
$status = data_get($document, 'analysis_status', '');
if (is_string($status) && in_array($status, ['needs_review', 'failed'], true)) {
```

### 4. AiCommunicationsMonitor.php
```php
// Before
$from = is_string($entry['from'] ?? null) ? $entry['from'] : '';
$text = is_string($entry['text'] ?? null) ? $entry['text'] : '';

// After
$from = is_string($entry['from']) ? $entry['from'] : '';
$text = is_string($entry['text']) ? $entry['text'] : '';
```
