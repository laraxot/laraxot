# Story 3.4 — PHPStan AiAssistant Module: 134 Errors

## Problem

PHPStan analysis on Modules/AiAssistant reports 134 errors.

## Error Details

### Primary Error Pattern
```
tests/Feature/LlmRawLoggingTest.php
  77   Call to method toBe() of internal class Pest\Mixins\Expectation<TValue>
  93   Call to method toBeEmpty() of internal class Pest\Mixins\Expectation<TValue>
  104  Call to method toBe() of internal class Pest\Mixins\Expectation<TValue>
  114  Call to method toHaveCount() of internal class Pest\Mixins\Expectation<TValue>
```

### Error Type
`method.internalClass` - Pest mixin methods called from outside namespace

## Root Cause

Using Pest mixin methods (`toBe()`, `toBeEmpty()`, `toHaveCount()`) directly on expectation objects instead of via `expect()`.

## Solution

Replace direct method calls with `expect()` pattern:

```php
// WRONG
$expectation->toBe($value);

// CORRECT
expect($value)->toBe($expected);
```
