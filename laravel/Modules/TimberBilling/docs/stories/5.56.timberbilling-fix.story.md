# BMAD Story — TimberBilling Module Systematic Fix

## Understand

Il modulo TimberBilling ha molti errori PHPStan:
- `generics.notGeneric`: Trait HasXotFactory usato in modo errato nei modelli (
  Activity, Snapshot, ecc.)
- `staticMethod.notFound`: chiamate al factory come `Modules\\AiAssistant\\Models\\AiThread::factory()`
- `method.nonObject` / `property.nonObject`: chiamata di metodi su mixed (es. `createOne()`),
  accesso a proprietà come `$id`, `$last_cost` su variabili typed come mixed

Regole applicabili:
- Non modificare mai phpstan.neon
- Sostituire `mixed` con tipi concreti
- Usare `UserContract` / `XotData` quando serve il modello utente
- Avere sempre factories definite per ogni modello che usa HasXotFactory

## Plan

1. Verificare `Modules\\Xot\\Models\\Traits\\HasXotFactory.php` e assicurarsi che sia generica.
2. Aggiungere `@phpstan-ignore` o correggere le chiamate del factory nei modelli.
3. Nei test, importare le factories corrette.

5. Eseguire `./vendor/bin/phpstan analyse Modules/TimberBilling --memory-limit=4G`

## Implement

### 1. Fix generics.notGeneric
Editare `Modules/Xot/Models/Traits/HasXotFactory.php`:
```php
namespace Modules\Xot\Models\Traits;

/**
 * @template TModel of \Illuminate\Database\Eloquent\Model
 */
trait HasXotFactory
{
    /**
     * Create a new factory instance for the model.
     *
     * @return \Illuminate\Database\Eloquent\Factories\Factory<TModel>
     */
    public static function factory(): \Illuminate\Database\Eloquent\Factories\Factory
    {
        /** @var class-string<TModel> $class */
        $class = static::class;
        return $class::factory();
    }
}
```

### 2. Aggiungere factories per i modelli senza
Controllare `Modules/AiAssistant/Models/AiThread.php` e assicurarsi che:
```php
class AiThread extends XotBaseModel
{
    use HasXotFactory;
    // factory definita in database/factories/AiThreadFactory.php
}
```

### 3. Sistemare i test che usano factory non conosciute
Modificare `Modules/AiAssistant/database/factories/AiActionProposalFactory.php`:
```php
/** @extends \Modules\AiAssistant\Models\AiThread */
class AiActionProposalFactory extends Factory
{
    protected $model = AiActionProposal::class;
    // ...
}
```

### 4. Aggiungere type hint espliciti nei test
Esempio in `Modules/Timber/tests/Feature/TimberStockMovementTest.php`:
```php
/** @var Modules\\Timber\\Models\\TimberProduct $product */
$product = TimberProduct::factory()->createOne();
```
