## Story

As a developer agent,
I want to audit and fix all model inheritance issues across modules,
so that the architecture rule "extend BaseModel/BasePivot/BaseMorphPivot, never Model directly" is enforced consistently.

## Understand

### Reference: Intervention.php (correct pattern)
- `Intervention` extends `BaseModel` (in `Modules/Intervention/app/Models/`)
- `BaseModel` extends `XotBaseModel`
- `XotBaseModel` uses `HasXotFactory` trait
- → `Intervention` already inherits `HasXotFactory` via `XotBaseModel`
- → `Intervention.php` does NOT use `use HasXotFactory;` → **CORRECT**

### Inheritance chain canonico
```
XotBaseModel → HasXotFactory (in XotBaseModel)
  └── BaseModel (module)
        └── <ConcreteModel>  ← NO use HasXotFactory (inherited)
```

### Why this works
- `XotBaseModel` uses `HasXotFactory` in the trait
- `BaseModel` extends `XotBaseModel` (no override)
- Concrete model extends `BaseModel`
- → Concrete model **inherits** HasXotFactory via class chain
- → `use HasXotFactory;` in concrete model = **redundant duplicate**

### Why redundant trait usage is wrong
- Creates duplicate trait "compile" calls
- Confuses PHPStan: "trait already used in parent class"
- Violates DRY: same trait used in 2 places
- Future bug: if HasXotFactory changes, both call sites must be updated

## Dev Notes

### Perché `use HasXotFactory;` è ridondante

`XotBaseModel`:
```php
abstract class XotBaseModel extends EloquentModel
{
    use HasXotFactory;
    use RelationX;
    use Updater;
    ...
}
```

`Intervention/BaseModel`:
```php
abstract class BaseModel extends XotBaseModel
{
    protected $connection = 'intervention';
}
```

`Intervention`:
```php
final class Intervention extends BaseModel
{
    // ← NO use HasXotFactory; perché già ereditato da XotBaseModel via BaseModel
}
```

### Come verificare se un trait è già ereditato

```bash
cd laravel
# Cerca "use HasXotFactory" ricorsivamente
grep -rn "use HasXotFactory;" Modules/Xot/app/Models/ --include="*.php"
# Se è solo in XotBaseModel/XotBasePivot/XotBaseMorphPivot, allora:
# - modelli che estendono BaseModel (Module) non devono ri-usarlo
```

### Convenzione di ereditarietà

| Tipo modello | Base | Esempio |
|---|---|---|
| Modello Eloquent normale | `BaseModel` (modulo) | `Comment`, `Intervention` |
| Pivot | `BasePivot` (modulo) | `UserTeam` |
| Morph pivot | `BaseMorphPivot` (modulo) | `CommentNotificationSubscription` |
