# Story 5.66 — Intervention Filament: Deprecated Methods Fix

## Problem

PHPStan reports **51 errors** in `Modules/Intervention`:

**Primary error pattern:**
```
method.deprecated — Call to deprecated method bulkActions() of class Filament\Tables\Table
Use `toolbarActions()` instead.
```

**Secondary errors:**
- `method.deprecatedClass` — Using deprecated Filament classes
- `class.notFound` — TestCase not found in test file (1 error)
- `ignore.unmatchedLine` — Stale ignore pattern (1 error)

## Root Cause

Filament v4 → v5 API migration. Methods like `bulkActions()` replaced with `toolbarActions()`.

## Solution

### Pattern: bulkActions() → toolbarActions()

```php
// WRONG
$table->bulkActions([
    Tables\Actions\RestoreAction::make(),
]);

// CORRECT
$table->toolbarActions([
    Tables\Actions\RestoreAction::make(),
]);
```

### Other deprecations to check

- `actions()` → check Filament docs for new method
- Column/form methods may have changed namespace
- Check for `@deprecated` PHPDoc in Filament source
