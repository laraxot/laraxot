# Story 5.71 — Billing: typeCoverage costanti (12 errori)

## Understand

PHPStan Level 10 segnala `typeCoverage.constantTypeCoverage` su costanti
`const` prive di dichiarazione di tipo esplicita. Le costanti vanno dichiarate
come `public const string`, `public const int`, `public const array`, ecc.

### File coinvolti (5 file, 12 costanti)

- `app/Actions/ReconcileSupplierInvoiceAction.php` — linee con costanti tipate male
- `app/Datas/AgingBuckets.php`
- `app/Datas/PreInvoiceLine.php`
- `app/Datas/ReconciliationDiscrepancy.php`
- `app/Queries/GetJobMarginsQuery.php`

## Plan

1. Per ogni costante, aggiungere il type hint esplicito (`string`, `int`, `array`).
2. Aggiungere `declare(strict_types=1);` se mancante.
3. Eseguire `phpstan analyse Modules/Billing --no-progress --memory-limit=-1`
4. Pest: `pest --filter=Billing`
