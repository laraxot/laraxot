# Story 4.6 — Browser test 4 Resources Billing

## Understand

Dopo la migrazione a canonical structure (story 4.1) e i fix PHPStan (4.1.1), le 4 Resources Billing devono essere testate runtime:

- `DeliveryNoteResource` (DDT ricevuti)
- `InvoiceResource` (Fatture cliente, con `isAvailableInCurrentPanel`)
- `SupplierResource` (Anagrafica fornitori)
- `SupplierInvoiceResource` (Fatture fornitore, con `reconcileAction` modale)

## Plan

### Test 1 — List page

Per ogni Resource, navigare a `/admin/<resource>` (o il path del pannello) e verificare:

- [ ] Tabella renderizza con tutte le colonne (number, supplier, received_on, lines_count, ...)
- [ ] Filtri funzionano (selezionare supplier, status, etc.)
- [ ] Ordinamento per colonna funziona
- [ ] Pagination visibile
- [ ] Record action (View, Edit, Delete) visibili
- [ ] Header action (Create, Bulk) visibili

### Test 2 — Create page

Per ogni Resource, navigare a `/admin/<resource>/create` e verificare:

- [ ] Form renderizza con tutti i campi (no campi mancanti rispetto a prima della migrazione)
- [ ] Select dinamici (es. `work_order_id` per `customer_id` selection) funzionano
- [ ] Date picker funziona
- [ ] Required validation visibile
- [ ] Salva un record di test
- [ ] Redirect a Edit page funziona
- [ ] Record appare in List

### Test 3 — Edit page

Per ogni Resource, navigare a `/admin/<resource>/<id>/edit`:

- [ ] Form pre-popolato con valori del record
- [ ] Salva modifiche
- [ ] Redirect a Edit page funziona
- [ ] Modifiche visibili in List

### Test 4 — View page (se presente)

- [ ] Infolist renderizza
- [ ] Tutti i campi visibili con label corrette
- [ ] Niente `Mixed` o errori

### Test 5 — Custom action (SupplierInvoiceResource)

- [ ] Azione "Concilia con i DDT" visibile in tabella
- [ ] Modale si apre
- [ ] Reconciliation result visibile (`view('billing::filament.reconciliation-result')`)
- [ ] Submit/Dismiss modale

### Test 6 — Authorization (InvoiceResource)

- [ ] Con `admin` user: visibile in menu
- [ ] Con `customer/*` URL: visibile ma `canCreate=false` (no Create button)
- [ ] Con `customer/*` URL: solo le proprie fatture visibili (`getEloquentQuery` filter)
- [ ] `isAvailableInCurrentPanel` rispetta `AccountFeatures`

## Implement

### Setup

```bash
cd laravel
php artisan serve --port=8000 &
# oppure usa `php artisan octane:start`
```

### Playwright

Usare lo script `bashscripts/docs/prompts/08-playwright-ui.md` come riferimento per setup.

```typescript
// Esempio per DeliveryNoteResource
test('DeliveryNoteResource list navigates', async ({ page }) => {
  await page.goto('/admin/delivery-notes');
  await expect(page.locator('h1')).toContainText('DDT');
  await expect(page.locator('table')).toBeVisible();
});
```
