# Story 3.5 — PHPStan Billing Module: 162 Errors

## Problem

PHPStan analysis on Modules/Billing reports 162 errors.

## Error Details

### Primary Error Pattern
```
tests/Unit/ProjectCashFlowActionTest.php
  161  Call to method toBe() of internal class Pest\Mixins\Expectation<TValue>
  161  Call to method toBeFalse() of internal class Pest\Mixins\Expectation<TValue>
  174  Call to method toBe() of internal class Pest\Mixins\Expectation<TValue>
  174  Call to method toBe() of internal class Pest\Mixins\Expectation<TValue>
```

### Error Type
`method.internalClass` - 162 instances of Pest mixin methods called incorrectly

## Root Cause

Test files using direct method calls on expectation objects instead of `expect()` pattern.

## Pattern to Fix

```php
// WRONG
$expectation->toBe($value);
$expectation->toBeFalse();

// CORRECT
expect($value)->toBe($expected);
expect($value)->toBeFalse();
```

## Plan

1. [ ] Scan all test files in Billing module
2. [ ] Convert all `->toBe()`, `->toBeFalse()`, etc. to `expect()` pattern
3. [ ] Run PHPStan to verify
4. [ ] Run PHPMD + PHPInsights + Pest
5. [ ] Git sync

## Search Pattern

```bash
rg "\->to[A-Z]\(" Modules/Billing/tests --include="*.php" | wc -l
```
