# BMAD Story — PublicProcurement canonical Filament structure

## Understand

Modulo `Modules/PublicProcurement` con 3 Filament Resources prive di Schemas/Tables estratti:
- `PublicProcurementContractResource`
- `PublicProcurementTenderOpportunityResource`
- `PublicProcurementTenderSourceResource`

Regole emerse da `Modules/Billing/docs/filament/patterns.md`:
- `Schemas/<Name>Form.php` extends `XotBaseResourceForm`
- `Tables/<Plural>Table.php` extends `XotBaseResourceTable`
- Resource slim: navigation + pages + relations, NO schema/table inline
- `$resource` property protected static in Schemas/Table
- Bug #1: `getTableActions()`/`getTableBulkActions()` devono esistere se inline li aveva
- Bug #2: namespace Actions in `Filament\Actions\*` (non `Tables`)
- Rating Base sono `abstract` → skip

## Plan

1. Leggere i 3 Resource file completi
2. Estrarre `getFormSchema()` → `Schemas/<Name>Form.php`
3. Estrarre `table()` → `Tables/<Plural>Table.php` (pattern `getTableColumns()`)
4. Slimmare Resource: rimuovere `getFormSchema()` e `table()` inline
5. Aggiungere `getTableActions()` e `getTableBulkActions()` nel Resource per azioni custom
6. Run `php -l` + `pint` su tutti i file
7. PHPStan bootstrap fail preesistente (Signage) → documentare
