# BMAD Story — Bom Filament canonical structure (4.14.11)

## Understand

1 Resource Bom: `BomResource` con schema/table inline (117 righe). Admin-only
(operator feature disabilitata). Ha RelationManager `BomItemsRelationManager`.

## Plan

1. Estrarre `getFormSchema()` in `Schemas/BomForm.php` (Select Product + Name + is_active)
2. Estrarre `table()` in `Tables/BomsTable.php` con `defaultSort('id', 'desc')`
3. Estrarre `getInfolistSchema()` in `Schemas/BomInfolist.php`
4. Slim del Resource: navigation + pages + relations + account features
5. Preservare `BomItemsRelationManager` in `getRelations()`

## Implement

**Resource slim** (60 righe, da 117):
- `BomResource.php` — `HasAccountFeatureVisibility` + `ACCOUNT_FEATURE_ADMIN = 'admin.bom'`,
  `ACCOUNT_FEATURE_OPERATOR = null` (admin-only), 4 pages

**3 classi nuove**:

| File | Note |
|---|---|
| `Schemas/BomForm.php` | Select Product (searchable, preload, required) + TextInput name + Toggle is_active |
| `Tables/BomsTable.php` | 5 colonne (id, product.name, name, is_active, updated_at), `getDefaultTableSortColumn()='id'`, `getDefaultTableSortDirection()='desc'`, `TernaryFilter::make('is_active')` |
| `Schemas/BomInfolist.php` | id + product.name + name + is_active + updated_at |

## Verify

Ripresa 2026-09-07 (sessione successiva): la bozza era stata lasciata a meta'
(WIP non committato, >40min senza tocchi, nessun lock/claim attivo) con 2
errori PHPStan reali e una **regressione funzionale silenziosa**: l'estrazione
di `getInfolistSchema()` in `BomInfolist.php` aveva sostituito l'intera feature
di visualizzazione ad albero della distinta base (ricorsiva, con guardia
anti-ciclo e profondita massima) con soli campi piatti, lasciando
`ViewBom::renderBomTree()` e la sua catena di metodi privati come codice morto
orfano invece di spostarli.

```bash

#    array<string,Component>

./vendor/bin/phpstan clear-result-cache && \
  ./vendor/bin/phpstan analyse Modules/Bom --memory-limit=-1 --no-progress
# [OK] No errors
```

`php -l` pulito sui 5 file toccati (`BomResource.php`, `ViewBom.php`,
`BomForm.php`, `BomInfolist.php`, nuovo test).
