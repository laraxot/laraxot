## Objective

Reduce prompts library from 133 files to ~30-40 coherent, non-redundant core prompts with complete YAML frontmatter. Improve maintainability, discoverability, and clarity.

## Current State (Audit 2026-09-05)

**File count:** 133 .md in bashscripts/docs/prompts/
**Archive:** 31 deprecated files in archive/ponytail/
**Active:** ~80-90 files (remainder duplicates, variants, superseded)

**Major issues:**
1. Duplicate semantics: 04-filament.md copies 04-datas-not-dtos.md, 05-widget.md copies 05-livewire-to-filament-widgets.md
2. Multiple entry points: START.md, START1.md, start.md, start_optimized.md all similar
3. Naming inconsistency: 16-git.md vs 16-git-forward-only.md, phpstan*.md (6+ variants)
4. Missing metadata: Most files lack YAML frontmatter with id, slug, category, status
5. Fragmentation: docs*.md (docs.md, docs1-4.md), phpstan*.md (phpstan.md, phpstan-module.md, phpstan_module.md, phpstan-all.md, phpstan-old.md, phpstan1.md, phpstan-module-analysis.md)

## Scope

### Phase 1: Audit & Categorization

**Deliverable:** Categorized inventory of all 133 files with recommendations:
- Keep (core, actively used)
- Merge (semantically duplicate, consolidate into one)
- Archive (deprecated, move to ponytail/)
- Delete (completely obsolete)

**Categories to emerge:**
- 00-master: Entry points, session bootstrap
- 01-10: Architecture, patterns, code standards
- 11-20: Repository ops, git, github, documentation
- 21-30: Specialized workflows (translations, testing, performance)
- 31-45: Full audits (module, filament, actions, etc.)
- 46-50: Orchestration, tools, rules

### Phase 2: Consolidation

**Merges to execute:**
1. START.md + START1.md + start.md + start_optimized.md → 00-master-prompt.md (one entry point)
2. phpstan.md + phpstan-module.md + phpstan_module.md + phpstan-all.md + phpstan1.md + phpstan-module-analysis.md → 11a-phpstan.md (one reference)
3. docs.md + docs1-4.md → 07b-documentation-standards.md (consolidate)
4. 04-filament.md → remove (dup of 04-datas-not-dtos.md, keep only latter)
5. 05-widget.md → remove (dup of 05-livewire-to-filament-widgets.md)
6. 06-filament.md, 06-filament-audit.md → keep 06-filament-audit.md, merge variants
7. 18-github.md + 19-github-discussions.md → 11c-github-operations.md (one source)

**Result:** 133 → ~35-40 core files

### Phase 3: Metadata Standardization

**Add to ALL core files:**
```yaml
---

document_type: operational_prompt|reference|guide|pattern
category: code|devops|testing|documentation|repository|workflow|orchestration

version: X.Y.Z
language: it-IT|en-US

updated_at: 'YYYY-MM-DD'

```

**Deliverable:** All 35-40 core files with valid YAML + git commit

## Risks & Mitigations

**Risk:** Breaking skills that reference hardcoded filename paths
- **Mitigation:** Audit all skills/rules for file references before executing merges; provide compatibility layer (symlinks or redirect comments)

**Risk:** Lost history/context if files merged too aggressively
- **Mitigation:** Archive all removed files, document migration path in MIGRATION-LOG.md

**Risk:** Team still refers to old filenames
- **Mitigation:** Announce consolidation, update INDEX.md, add redirect comments in merged files pointing to new location

## Notes

This consolidation was identified in audit 01.01 (module documentation cleanup). Prompts library suffers similar entropy: 130+ files have accumulated without deduplication discipline. Excellence requires ruthless consolidation, clear metadata, and a small set of authoritative sources.

Prerequisite: Audit only, no execution without BMAD plan gate.
