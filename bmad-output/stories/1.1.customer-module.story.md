# Story 1.1 — Customer Module

- **Epic:** 1 — Core Field Service
- **Status:** backlog
- **Module:** `laravel/Modules/Customer/`
- **Dependencies:** User (Auth)
- **Estimated effort:** 1 dev-day

---

## Story

As an admin, I want to manage customers with their sites and contacts, so that every work order can be assigned to a customer.

---

## Acceptance Criteria

1. Customer CRUD with `XotBaseResource`: legal name, VAT number, tax code, email, phone, addresses (address_line1/line2, city, postal_code, province, country_code), payment method (bonifico/sepa/carta/contanti), IBAN, notes, `is_active` toggle, soft-deletes. Searchable by `legal_name`, `vat_number`, `city`, `email`, `phone`. [Source: prd.md#FR-01]
2. CustomerSite management: multiple sites per customer (name, address, contacts relation). `Customer` → `HasMany<CustomerSite>`. [Source: prd.md#FR-01]
3. Contact management role-based: `Contact` belongs to `Customer` and optionally to `CustomerSite`, linked to `ContactRole` lookup table (seeded roles). `Contact` stores `full_name`, `email`, `phone`, `role_id`. [Source: prd.md#FR-01]
4. Reseller (intermediary) management: `Reseller` model with `name`, linked to `User`. Separate `ResellerResource` gated behind `admin.resellers` feature flag. [Source: prd.md#FR-01]
5. Feature visibility gating via `AccountFeatures` on both Customer and Reseller resources — `admin.customers` / `admin.resellers`. `getEloquentQuery` scoped by `AccountFeatures::scopeAssignedCustomers` for admin perimeter users. [Source: prd.md#FR-01]
6. Relation managers on Customer view: `WorkOrdersRelationManager` (inline count + list), `CustomerSitesRelationManager`, `ContactsRelationManager`. [Source: architecture.md#wave-1]
7. Global search with record title `legal_name`, searchable attributes including `vat_number`, `tax_code`, `email`, `phone`, `city`. Result details show VAT, city, phone. [Source: architecture.md#wave-1]

## Dev Notes

- Module name: `Customer` (singular PascalCase per NFR-04). SRC exists at `Modules/Customers` (plural DDD structure) — **not ported as-is**. Create new module at `laravel/Modules/Customer/` with flat nwidart structure. [Source: architecture.md#wave-1]
- Namespace target: `Modules\Customer\app\Models\Customer`, `Modules\Customer\app\Filament\Resources\CustomerResource`. [Source: architecture.md#module-boundary-architecture]
- All models extend `XotBaseModel` (NFR-01). All resources extend `XotBaseResource` (NFR-01). All actions use `Spatie\QueueableAction` trait (NFR-01). All policies extend `UserBasePolicy`.
- SRC references to port (from `Modules\Customers\Infrastructure\Models\*`):
  - `Customer`: `$guarded`, `SoftDeletes`, casts (`is_active` bool, `deleted_at` datetime), relations: `sites()`, `contacts()`, `workOrders()`
  - `CustomerSite`: `$table = 'customer_sites'`, relations: `customer()`, `contacts()`
  - `Contact`: `$guarded`, `SoftDeletes`, relations: `customer()`, `site()`, `role()`
  - `ContactRole`: lookup, `$guarded`, relation: `contacts()`
  - `Reseller`: `SoftDeletes`, relation: `user()`
- Filament SRC resources (`CustomerResource`, `ResellerResource`) use `Filament\Resources\Resource` — convert to `XotBaseResource`. No `AccountFeatures` class in target yet — stub or import from `app/Support/`.
- SRC DB connection: `xot` (all business modules).
- SRC form fields: legal_name (required), vat_number, tax_code, email (email()), phone (tel()), address_line1/line2, city, postal_code, province, country_code (select IT/SM/CH/DE/FR/AT), payment_method (select), iban (visible when bonifico), notes (textarea), is_active (toggle default true).
- SRC table columns: legal_name (bold, searchable, sortable), email (icon, copyable, toggleable), phone (icon, toggleable), city (toggleable, sortable), is_active (boolean icon), updated_at (toggleable hidden).
- SRC filters: TernaryFilter on `is_active`.
- SRC pages: ListCustomers, CreateCustomer, ViewCustomer, EditCustomer — all extend `XotBase*` equivalents.
- SRC Resource pages directory: `Filament/Resources/CustomerResource/Pages/` with `ListCustomers`, `CreateCustomer`, `ViewCustomer`, `EditCustomer`.
- SRC RelationManagers: `WorkOrdersRelationManager`, `CustomerSitesRelationManager`, `ContactsRelationManager` in `Filament/Resources/CustomerResource/RelationManagers/`.
- DB connection for all Customer models: `xot`.
- Translations in `Resources/lang/{it,en}/` — mirror SRC `resources/lang/` keys.
- `InterventionMaterialLine` in Intervention module references `QuotationItem` — out of scope for this story, leave as commented relationship or TODO.
