# BMAD Story — Module Root MD File Limit Enforcement

## Understand

- **Problema**: Le root dei moduli hanno troppi file .md (oltre 6)
- **Regola**: Massimo 6 file .md nelle root dei moduli
- **Obiettivo**: Identificare, valutare, e spostare o rimuovere file .md in eccesso

## Plan

1. Scansionare tutte le root di modulo per contare file .md
2. Identificare file .md in eccesso
3. Per ogni file .md in eccesso:
   - Se è documentazione importante → spostarla in `docs/wiki/` o `docs/`
   - Se è duplicato o obsoleto → segnare per rimozione
4. Aggiornare il README principale se necessario
5. Verificare con git status
6. Commit e sync

## Implement

### Step 1: Scansione moduli

Eseguo script per identificare tutti i file .md per modulo.

### Step 2: Decisione per ogni file

- `README.md` → sempre conservato (documentazione principale)
- `CHANGELOG.md` → spostare in `docs/` o archiviare
- `docs/` folder → contiene già file .md, non duplicare nella root
- `PRD.md` → spostare in `docs/product/`
- `composer.json` → non è .md (escludere)
