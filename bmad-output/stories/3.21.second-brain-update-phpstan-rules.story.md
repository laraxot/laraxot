### 3. Cast Mixed: cast.string/cast.int
- **Pattern**: `(string)` or `(int)` cast on mixed
- **Fix**: Add type check before cast
```php
// WRONG
$value = (string) $mixed;

// CORRECT
$value = is_string($mixed) ? $mixed : '';
```

### 4. Generic Trait @phpstan-use
- **Pattern**: `@phpstan-use Trait<Type>` on non-generic trait
- **Fix**: Remove annotation if trait is not generic

### 5. User Model Pattern
- **Rule**: Use `UserContract` or `XotData::getUserClass()`
- **Never**: Direct `User::class` references

### 6. Profile Model Pattern
- **Rule**: Use `XotData::getProfileClass()`
