## Acceptance Criteria

### AC-01 — Quotation CRUD linked to Customer
Quotation model (code, title, status_code, notes, subtotal, tax_amount, total, issued_at, confirmed_at, soft-deletes) with Filament Resource. Extends XotBaseModel. BelongsTo Customer and optional WorkOrder. Status machine via `status_code` lookup.

### AC-02 — QuotationItem with product/price/quantity
QuotationItem model (description, quantity, unit_price, line_total, sort_order). BelongsTo Quotation (cascade) and optional Product. Filament ItemsRelationManager on QuotationResource. All decimal casts for financial fields.

### AC-03 — Quotation totals calculation
CalculateQuotationTotalsAction with Spatie QueueableAction. QuotationTotals DTO for subtotal/tax/total. Triggered on save/update of items. Reuses Money value object.

### AC-04 — QuotationTemplate for reuse
QuotationTemplate + QuotationTemplateItem models. Template hasMany items with same price/quantity/discount fields. DuplicateQuotationAsDraftAction to instantiate from template.

### AC-05 — SiteSurvey as pre-quote assessment
SiteSurvey model (scheduled_at, performed_at, notes). BelongsTo Customer, optional CustomerSite, WorkOrder, Quotation, User (performed_by). MorphMany Media for photos/videos/voice notes. SiteSurveyResource with Create/Edit/List/View pages.

### AC-06 — Quotation PDF generation
GenerateQuotationPdfAction and GenerateConfirmedQuotationPdfAction. Both use QueueableAction. PDF output stored via Media morph.

### AC-07 — Flatten to Laraxot structure
Move models from `Infrastructure/Models/` to `app/Models/`, policies from `Infrastructure/Policies/` to `app/Policies/`, Filament resources to `app/Filament/Resources/`, actions from `Domain/Actions/` and `Application/Actions/` to `app/Actions/`, DTOs to `app/DTO/`. Reconcile all namespace imports.
