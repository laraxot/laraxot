## Acceptance Criteria

### AC-01 — Product CRUD
Product model (name, sku, description, unit_price, is_active, soft-deletes) with Filament Resource. Extends XotBaseModel. ProductResource extends XotBaseResource.

### AC-02 — Classification axes lookup CRUD
CatalogModel (name), CatalogPartType (name), CatalogMeasureUnit (name, symbol), CatalogFrequency (name, sort_order). Each: model + Resource + Policy. All extend XotBaseModel.

### AC-03 — Product-classification relationships
Product belongsTo each classification axis. Migration with FK: `catalog_model_id`, `catalog_part_type_id`, `catalog_measure_unit_id`, `catalog_frequency_id`.

### AC-04 — MetelCatalog import structure
MetelCatalog (code, brand_code, name, manufacturer, source_type, version, imported_at, is_active) and MetelCatalogItem (metel_code, barcode, etim_code, description, unit_of_measure, packaging, gross_price, net_price) models + Resources. MetelCatalog hasMany MetelCatalogItem.

### AC-05 — MetelCatalog import integration
FetchMetelCatalogViaApiAction, ImportMetelPriceListFileAction, LinkMetelItemToProductAction, MetelRecordParser. All use Spatie QueueableAction. MetelArticleData DTO for data transfer.

### AC-06 — Flatten to Laraxot structure
Move models from `Infrastructure/Models/` to `app/Models/`, policies from `Infrastructure/Policies/` to `app/Policies/`, Filament from `Filament/Resources/` to `app/Filament/Resources/`, actions from `Application/Actions/` to `app/Actions/`, DTOs from `Application/DTO/` to `app/DTO/`. Reconcile all namespace imports across the module and callers.

### AC-07 — Translation strings and navigation
All label/singular/plural strings in `Resources/lang/{it,en}/catalog.php`. Navigation group under Commerciale. Feature gating via `AccountFeatures`.
