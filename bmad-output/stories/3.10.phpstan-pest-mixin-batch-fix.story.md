# Story 3.10 — Batch Fix: Pest Mixin Methods (AiAssistant + Billing)

## Problem

PHPStan reports `method.internalClass` errors in AiAssistant (134) and Billing (160) modules.

```
Call to method toBe() of internal class Pest\Mixins\Expectation<TValue>
```

## Root Cause

Test files use direct method calls on Pest expectation objects instead of `expect()` pattern.

## Error Pattern

```php
// WRONG - causes method.internalClass
$expectation->toBe($value);
$expectation->toBeEmpty();
$expectation->toBeFalse();

// CORRECT
expect($value)->toBe($expected);
expect($collection)->toBeEmpty();
```
