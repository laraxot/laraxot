# Story 3.22 — PHPMD + PHPInsights Fixes Campaign

## Problem

Focus has been on PHPStan, but PHPMD and PHPInsights may have violations that need fixing.

## Tools Available

```bash
# PHPMD
./tools/phpmd.sh <file> text phpmd.xml

# PHPInsights
./vendor/bin/phpinsights analyse <file> --no-interaction
```

## Plan

1. [ ] Run PHPMD on all modules to get violations
2. [ ] Run PHPInsights on all modules to get insights
3. [ ] Categorize violations
4. [ ] Fix violations module by module
5. [ ] Git sync after each module

## Initial Scan

```bash
cd laravel
for mod in $(ls -d Modules/*/ | sed 's|/$||' | xargs -n1 basename); do
  echo "=== $mod PHPMD ==="
  ./tools/phpmd.sh Modules/$mod 2>&1 | head -20
  echo "=== $mod PHPInsights ==="
  ./vendor/bin/phpinsights analyse Modules/$mod --no-interaction 2>&1 | tail -10
done
```

## Common PHPMD Violations

- NPath complexity
- Cyclomatic complexity
- Too many methods
- Too many fields
- Coupling between objects

## Common PHPInsights Issues

- Code style
- Security
- Architecture
- Dead code

## Verification

```bash
./tools/phpmd.sh Modules/<ModuleName>
./vendor/bin/phpinsights analyse Modules/<ModuleName> --no-interaction
```
