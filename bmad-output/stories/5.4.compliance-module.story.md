# Story — 5.4 Compliance Module

**Epic:** 5 — Manufacturing & Verticali
**Status:** backlog
**Owner:** Modules\Compliance

## Intent

As a compliance officer, I want to manage heating systems, boilers, compliance documents, subcontractors, and work order change orders, so that regulatory obligations and subcontractor relationships are tracked.

## Dev Notes

- SRC Compliance module has 3 migration files: base compliance tables, heating maintenance tables, and customer systems. The base migration creates subcontractors, compliance_documents, work_order_change_orders, equipment, and work_order_readiness_items. [Source: SRC `Modules/Compliance/Database/Migrations/2026_05_06_120000_create_compliance_tables.php`, `2026_07_13_130000_create_heating_maintenance_tables.php`, `2026_07_22_120000_create_customer_systems_table.php`]
- ComplianceDocument has polymorphic FKs across multiple entities: work_order, customer, employee, vehicle, subcontractor, equipment. These are stored as explicit nullable FK columns (not a true morph). [Source: SRC migration]
- SRC models use `$guarded = []` — target uses `$fillable`. [Source: `laravel/AGENTS.md`]
- HeatingSystem/Boiler domain is specific to Italian heating compliance (libretto impianto, RCEE, bollino, controlli fumi). Keep Italian terminology where domain-specific (fuel_type, rcee_type, bollino_code, outcome values). [Source: SRC migration field definitions]
- MaintenanceControl combustion analysis columns are nullable — not all controls require full analysis. [Source: SRC migration]
- WorkOrderChangeOrder `status` lifecycle: proposed → approved → executed → billed, or proposed → rejected. Approval flow requires admin action. [Source: SRC migration]
- AI processing fields on ComplianceDocument are for future AI classification story (6.3/6.4) — store-only in this story, no processing logic. [Source: prd.md#FR-06]
- Equipment links to WorkOrder (Epic 1) via `assigned_work_order_id`. [Source: SRC migration]
- Subcontractor `business_name` is required, other fields nullable. [Source: SRC model]
