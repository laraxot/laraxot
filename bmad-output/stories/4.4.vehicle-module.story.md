## Acceptance Criteria

### AC-01 — Vehicle CRUD
Vehicle model (plate_number unique, make, model, year, notes, is_active, soft-deletes). Extends XotBaseModel. VehicleResource extends XotBaseResource with List/Create/Edit/View pages.

### AC-02 — VehicleDocument relation manager
VehicleDocument model (title). BelongsTo Vehicle (cascade). BelongsTo Media for file storage (insurance, inspection docs). Unique constraint on (vehicle_id, media_id). DocumentsRelationManager on VehicleResource.

### AC-03 — AddVehicleDocumentAction
QueueableAction accepting vehicle_id, file, title. Creates Media record, creates VehicleDocument record. Uses Spatie Media Library for file storage.

### AC-04 — Vehicle filtering and search
Vehicle table: searchable by plate_number. Filter by is_active status.

### AC-05 — Policy gating
VehiclePolicy extending UserBasePolicy. Feature visibility via AccountFeatures. Navigation grouped under Fleet.

### AC-06 — Vehicle extended maintenance fields (optional)
Migration for odometer_km (integer), last_service_on (date), insurance_expires_on (date). These are tracked in the SRC but marked as optional — include if time permits.

### AC-07 — Flatten to Laraxot structure
Move models from `Infrastructure/Models/` to `app/Models/`, policies from `Infrastructure/Policies/` to `app/Policies/`, Filament resources to `app/Filament/Resources/`, actions from `Application/Actions/` to `app/Actions/`.
