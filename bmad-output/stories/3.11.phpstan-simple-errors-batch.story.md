# Story 3.11 — Batch Fix: Simple PHPStan Errors

## Problem

4 modules with simple, easily fixable errors totaling 23 issues.

## Modules Summary

| Module | Errors | Type |
|--------|--------|------|
| Blog | 12 | cast.string, cast.int |
| AI | 9 | Pest assertions |
| AsdSoci | 1 | TBD |
| Dds | 1 | TBD |

## Plan

### 1. Blog (12 errors)
Fix `cast.string` and `cast.int`:
```php
// WRONG
$value = (string) $data['key'];
$id = (int) $mixedValue;

// CORRECT
$value = is_string($data['key'] ?? null) ? $data['key'] : '';
$id = is_numeric($mixedValue) ? (int) $mixedValue : 0;
```

### 2. AI (9 errors)
Fix `method.notFound` - `assertLessThanOrEqual`, `assertStringStartsWith`, etc.:
```php
// WRONG
$result->assertLessThanOrEqual();

// CORRECT
expect($result)->toBeLessThanOrEqual();
```

### 3. AsdSoci + Dds (1 error each)
Analyze and fix single errors.

./vendor/bin/phpstan analyse Modules/Blog Modules/AI Modules/AsdSoci Modules/Dds
